# Lotus Discord — Purple Glassmorphism Theme for Vencord

A dark purple glassmorphism theme for Discord (Vencord) matching the Lotus-Arch desktop aesthetic.

## Palette

| Token | Hex |
|-------|-----|
| Background | `#141218` |
| Background Alt | `#1C1A22` |
| Background Light | `#282430` |
| Primary Accent | `#C4A8E2` |
| Primary Dim | `#8C7AA6` |
| Primary Dark | `#383048` |
| Text | `#D8D0E8` |
| Text Dim | `#887898` |

## Install

1. **Vencord**: Copy `themes/lotus-purple.theme.css` to `~/.config/Vencord/themes/`
2. Enable in Vencord settings → Themes → toggle on "Lotus Purple"

Or use the direct import URL if hosted.

## What's themed

- Sidebar, chat, members list, panels
- Buttons, scrollbars, context menus, modals
- Input fields, search bar, embeds, reactions
- Mentions, code blocks, bot tags, tooltips
- Call/voice UI, Spotify status, threads
- Glass blur effects on top bars and panels

## Compatible with

- Discord (via Vencord)
- Vesktop (Vencord built-in)
